1 二次根式的定义

一般地，形如 √a (a ≥ 0) 的式子叫做二次根式。其中符号"√"叫做二次根号，a 叫做被开方数。

二次根式 = √a   (a ≥ 0)
被开方数 a 必须是非负数，这是二次根式有意义的根本条件
⚠ 核心条件：被开方数必须非负
在实数范围内，负数没有平方根，所以被开方数 a 必须 ≥ 0。当 a < 0 时，√a 无意义。

判断方法：看到 √( )，就问"括号里的式子是否 ≥ 0？"
· √5 —— 被开方数 5 > 0，有意义
· √(−3) —— 被开方数 −3 < 0，无意义
· √0 —— 被开方数 0 = 0，有意义，√0 = 0
· √(x−2) —— 有意义要求 x − 2 ≥ 0，即 x ≥ 2
  • 是二次根式：√5、√(a²+1)、√0 —— 被开方数 ≥ 0
  • 无意义：√(−7)、√(−x²−1) —— 被开方数 < 0
  • 条件有意义：√(x−3) —— 要求 x ≥ 3；√(2−x) —— 要求 x ≤ 2

3 二次根式的性质

二次根式有以下重要性质，它们是二次根式运算的理论基础。请特别注意每条性质中字母的取值范围。

性质 1
(√a)² = a
a ≥ 0（先开方再平方，回到本身）
性质 2（最重要）
√(a²) = |a|
a 为任意实数（必须取绝对值！）
性质 3·乘法
√(ab) = √a · √b
a ≥ 0，b ≥ 0
性质 4·除法
√(a/b) = √a / √b
a ≥ 0，b > 0
⚠ 最易错：√(a²) = |a|，不是 a！
性质 2 是中考高频考点。√(a²) 的结果一定是非负数，所以必须加绝对值符号：

· 当 a ≥ 0 时，√(a²) = |a| = a
· 当 a < 0 时，√(a²) = |a| = −a（注意是 −a，不是 a！）

例：√(−5)² = |−5| = 5，不等于 −5。
例：√(x²) = |x|（不知道 x 正负时必须保留绝对值）。

对比性质 1 和性质 2：(√a)² = a 要求 a ≥ 0；而 √(a²) = |a| 对任意实数 a 都成立。先平方后开方与先开方后平方的运算顺序不同，条件和结果也不同！
💡 性质 3、4 的记忆
乘法性质 √(ab) = √a · √b 可以"拆开"：根号内的乘积可以拆成两个根号的乘积。
除法性质 √(a/b) = √a / √b 可以"拆开"：根号内的商可以拆成两个根号的商。
这两个性质反过来用，就是化简二次根式和二次根式乘除运算的依据。

正确：√(a²) = |a|   （对任意实数 a 都成立）

口诀："先平方后开方，加个绝对值不会差"。因为平方把负数变正了，开方结果一定是非负的，所以必须用绝对值保证非负性。

5 最简二次根式

满足以下两个条件的二次根式，叫做最简二次根式：

条件 1
被开方数不含分母
如 √3、2√5 满足，√(1/2) 不满足
条件 2
被开方数不含能开尽方的因数
如 √3 满足，√12 = 2√3 不满足（含 4）
💡 化简方法
把被开方数分解因数，找出其中最大的完全平方因数（如 4、9、16、25、36、49、64……），利用 √(ab) = √a · √b 把它"开出来"。

示例：√12 = √(4×3) = √4 × √3 = 2√3   （4 = 2² 是完全平方数，开出来变成 2）
示例：√50 = √(25×2) = √25 × √2 = 5√2   （25 = 5² 开出来变成 5）
⚠ 找"最大"完全平方因数
化简时一定要找最大的完全平方因数，否则还需继续化简。
如 √72：72 = 4×18 = 36×2，其中 4 和 36 都是完全平方数，但 36 更大。应该用 36×2：
√72 = √(36×2) = 6√2   ✓
如果用 4×18：√72 = √(4×18) = 2√18，但 √18 还能继续化简（18 = 9×2），所以 2√18 = 2×3√2 = 6√2，多走了一步。

7 同类二次根式

把几个二次根式化为最简二次根式后，如果它们的被开方数相同，那么这几个二次根式就叫做同类二次根式。

同类二次根式 ⟺ 化为最简后，被开方数相同
与"同类项"类似：同类项是字母和指数相同，同类二次根式是被开方数相同
💡 判断步骤
第一步：把每个二次根式化为最简二次根式。
第二步：比较被开方数是否相同。

示例：√8、√18、√50 是否为同类二次根式？
√8 = 2√2，√18 = 3√2，√50 = 5√2
化简后被开方数都是 2，所以它们是同类二次根式。

注意：√2 和 √3 不是同类（被开方数 2 ≠ 3）；√12 = 2√3 和 √3 是同类（化简后都是 √3）。

9 二次根式的运算

二次根式的运算与整式、分式的运算一脉相承，关键是先化为最简二次根式，再进行运算。

加减法
先化最简，再合并同类
类似于合并同类项
乘法
√a · √b = √(ab)
a ≥ 0，b ≥ 0
除法
√a / √b = √(a/b)
a ≥ 0，b > 0
⚠ 加减法的核心步骤
第一步：化简——把每个二次根式化为最简二次根式。
第二步：合并同类——把同类二次根式（被开方数相同）的系数相加减，被开方数不变。

这与合并同类项完全类似：3√2 + 2√2 = (3+2)√2 = 5√2，就像 3x + 2x = 5x。
注意：只有同类二次根式才能合并！√2 + √3 不能合并，就像 x + y 不能合并一样。
💡 乘除法示例
乘法：√2 × √6 = √(2×6) = √12 = 2√3（结果要化为最简）
除法：√8 ÷ √2 = √(8/2) = √4 = 2
混合：√3 × √2 = √6，√6 ÷ √2 = √3

12 学科交叉参考

🔗 二次根式的延伸与应用
  • ✂️ 数学·分式—— 二次根式与分式有相似的化简思想：分式约分去公因式，二次根式化简去完全平方因数。此外，分母有理化（如把 1/√2 化为 √2/2）本质上就是分子分母同乘 √2，是分式基本性质在二次根式中的应用。 化简思想
  • 📐 数学·勾股定理—— 勾股定理 a² + b² = c² 的计算中大量出现二次根式。例如直角边为 1 和 2 时，斜边 c = √(1²+2²) = √5。化简勾股定理的结果时，需要用到二次根式的化简技巧。二次根式是勾股定理计算的必备工具。 几何应用
  • 🔢 数学·整式的乘除—— 二次根式的乘除法则 √(ab) = √a·√b 与整式乘法的运算律一致，二次根式的加减合并同类也与整式加减合并同类项完全类似。整式运算的法则可以直接迁移到二次根式。 运算迁移
