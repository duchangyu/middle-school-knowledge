💡 核心问题

数据的分析要回答三个核心问题：数据的集中趋势（平均数、中位数、众数）、数据的离散程度（极差、方差）、以及用样本估计总体。

2 平均数（算术平均数）

一般地，对于 n 个数据 x₁, x₂, ..., xₙ，它们的算术平均数（简称平均数）为：

x̄ = (x₁ + x₂ + ... + xₙ) / n
平均数反映了一组数据的"一般水平"，它利用了所有数据的信息
📐 注意
  • 平均数受极端值（特大或特小的值）影响较大
  • 平均数不一定是数据中的某个值
  • 平均数的单位与原数据相同

4 加权平均数

若 n 个数据中，x₁ 出现 f₁ 次，x₂ 出现 f₂ 次，……，xₖ 出现 fₖ 次（f₁ + f₂ + ... + fₖ = n），则这组数据的加权平均数为：

x̄ = (x₁f₁ + x₂f₂ + ... + xₖfₖ) / (f₁ + f₂ + ... + fₖ)
其中 f₁, f₂, ..., fₖ 称为权（weight），它反映了各数据在总体中的重要程度
💡 理解"权"

"权"越大，说明该数据在总体中占的比重越大，对平均数的影响也越大。算术平均数是加权平均数的特殊情况——每个数据的"权"都相等（都是 1）。

6 中位数和众数

中位数

将一组数据按从小到大（或从大到小）的顺序排列后，处在最中间位置的一个数据（或最中间两个数据的平均值），叫做这组数据的中位数。

n 为奇数
最中间的那一个
n 为偶数
最中间两个的平均

众数

一组数据中出现次数最多的数据叫做这组数据的众数。

📐 众数的特点
  • 众数可能有一个、多个，也可能没有（当所有数据出现次数相同时）
  • 众数是数据中的原始值，而不是出现的次数
  • 众数常用于描述"最常见"的情况

8 极差和方差

极差

一组数据中的最大值与最小值的差，叫做这组数据的极差。

极差 = 最大值 − 最小值
极差反映数据的变化范围，简单但只利用了两个数据

方差

设 n 个数据 x₁, x₂, ..., xₙ 的平均数为 x̄，则这组数据的方差为：

s² = [(x₁−x̄)² + (x₂−x̄)² + ... + (xₙ−x̄)²] / n
方差反映数据的离散程度。方差越小，数据越稳定；方差越大，数据波动越大
💡 方差的意义
  • 方差是各数据与平均数之差的平方的平均数
  • 方差≥0；当且仅当所有数据相等时，方差=0
  • 方差的单位是原数据单位的平方
  • 比较两组数据的稳定性时，方差小的更稳定

10 用样本估计总体

在现实生活中，当总体包含的个体数目很多甚至无限时，我们通常无法对每个个体进行调查。这时可以从总体中抽取一个样本，用样本的特征来估计总体的特征。

样本平均数 → 估计 → 总体平均数
样本方差 → 估计 → 总体方差
样本量越大，样本对总体的估计越准确
💡 抽样调查
  • 总体：所要考察的全体对象
  • 个体：组成总体的每一个考察对象
  • 样本：从总体中抽取的一部分个体
  • 样本容量：样本中个体的数目
  • 抽样时要注意样本的代表性和广泛性
