1 引入：直角三角形的三边关系

在一个直角三角形中，两条直角边分别记为 a 和 b，斜边（直角所对的边）记为 c。

早在公元前 11 世纪，中国古代数学家就发现了一个奇妙的规律：直角三角形两条直角边的平方和，等于斜边的平方。这个结论被称为勾股定理（西方称为毕达哥拉斯定理）。

a2 + b2 = c2
直角边 a、b 的平方和 = 斜边 c 的平方
💡 小知识
古称直角三角形短直角边为「勾」，长直角边为「股」，斜边为「弦」，故得名「勾股定理」。三国时期数学家赵爽用「弦图」给出了优美的证明。

3 交互探索：赵爽弦图（拼图证明）

三国时期数学家赵爽用四个全等的直角三角形拼成一个大正方形，中间自然形成一个小正方形——这就是著名的「弦图」。通过面积关系，可以优美地证明勾股定理。

📐 面积关系（以 a=3, b=4, c=5 为例）

大正方形面积 = (a+b)2 = 4 个三角形面积 + 小正方形面积

即 (a+b)2 = 4 × (½ab) + c2

展开：a2 + 2ab + b2 = 2ab + c2

两边减去 2ab，得到：a2 + b2 = c2 ∎

4 勾股数

满足 a2 + b2 = c2 的三个正整数 (a, b, c) 称为勾股数。点击「随机验证」按钮，随机抽取一组勾股数进行验证。

3, 4, 5
3² + 4² = 9 + 16 = 25 = 5²
5, 12, 13
5² + 12² = 25 + 144 = 169 = 13²
8, 15, 17
8² + 15² = 64 + 225 = 289 = 17²
7, 24, 25
7² + 24² = 49 + 576 = 625 = 25²
💡 规律发现
勾股数有一个重要性质：把一组勾股数同时乘以同一个正整数 k，得到的 (ka, kb, kc) 仍然是勾股数。例如由 (3,4,5) 可得 (6,8,10)、(9,12,15) 等。

5 实际应用

勾股定理在生活中有广泛应用——只要涉及直角三角形，就可以用它来求未知边长。

🪜 梯子靠墙问题

一架 5 米长的梯子斜靠在墙上，梯脚距墙根 3 米，梯顶距地面多高？

b = √(c2 - a2) = √(52 - 32)
  = √(25 - 9) = √16
  = 4 米

🪁 风筝线问题

风筝在空中高度 12 米，放出风筝线的水汗距离 5 米，风筝线有多长？

c = √(a2 + b2) = √(52 + 122)
  = √(25 + 144) = √169
  = 13 米

7 学科交叉参考

🔗 勾股定理在其他学科中的应用
  • ⚡ 物理·力的合成—— 两个互相垂直的分力 F₁、F₂ 的合力 F 的大小满足 F = √(F₁² + F₂²)，这正是勾股定理在矢量合成中的应用。力的平行四边形定则中，垂直分力构成的直角三角形，斜边就是合力。 矢量三角形
  • ⚡ 物理·浮力—— 浮力问题中常涉及物体在液体中的几何计算，如斜面上物体的位移分解、浮力与重力的合力分析，都需要用勾股定理计算矢量分量。 力的分解
