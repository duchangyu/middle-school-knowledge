⚫ 第六单元：碳和碳的氧化物

同一种元素——碳，竟能构成自然界最硬的金刚石和 最软的石墨之一；碳的两种氧化物 CO 和 CO₂ 性质更是天差地别。 本单元核心思想：结构决定性质，性质决定用途。

1碳的单质

💎 金刚石
无色透明、正八面体形状的固体，是天然存在的最硬的物质。
结构：每个碳原子与 4 个碳原子相连，构成空间网状结构。
用途：裁玻璃、切割大理石、钻探机钻头、装饰品（钻石）。
✏️ 石墨
深灰色、有金属光泽、不透明的细鳞片状固体，质软、有滑腻感、能导电。
结构：层状结构，层与层之间作用力弱，易滑动。
用途：铅笔芯、电极、润滑剂。
⚽ C₆₀（足球烯）
由 60 个碳原子构成的分子，形似足球，结构稳定。
应用前景：超导、催化、材料、医学等领域。
注意：C₆₀ 是由分子构成的碳单质。
💡 为什么性质差别这么大？
金刚石、石墨、C₆₀ 都是由碳元素组成的单质，化学性质相似，但物理性质差异很大， 原因是：碳原子的排列方式不同。这就是"结构决定性质"的最好例证。
此外，木炭和活性炭具有疏松多孔的结构，有吸附性，可用来吸附色素、异味和毒气（防毒面具）。 吸附属于物理变化。

2碳的化学性质

  • 🛡️常温下化学性质稳定：古代字画（用墨书写，墨的主要成分是碳）历经千年不褪色，就是利用了碳在常温下的稳定性。
  • 🔥可燃性（点燃）：氧气充足时充分燃烧生成 CO₂；氧气不充足时生成有毒的 CO。
  • 🧲还原性（高温）：碳能夺取某些氧化物中的氧，把金属还原出来，可用于冶金工业。
C + O₂ —点燃→ CO₂ 氧气充足，充分燃烧（发出白光，放热）
2C + O₂ —点燃→ 2CO 氧气不足，不充分燃烧，生成有毒的一氧化碳
C + 2CuO —高温→ 2Cu + CO₂↑ 碳的还原性：黑色粉末变红，生成的气体使石灰水变浑浊
⚠️ 还原反应与还原剂：含氧化合物里的氧被夺去的反应叫还原反应。上述反应中，CuO 失去氧被还原成 Cu； 碳夺取了氧，具有还原性，是还原剂（还原剂被氧化）。

验交互二：碳还原氧化铜实验模拟

C + 2CuO —高温→ 2Cu + CO₂↑

点击"加热"观察：黑色粉末逐渐变红，澄清石灰水变浑浊。注意实验结束时"先撤导管、后熄灯"！
反应前：黑色混合物粉末
🔍 实验要点
现象：黑色粉末逐渐变成红色（生成铜），导管口有气泡，澄清石灰水变浑浊（生成 CO₂）。
操作：实验结束时，必须先把导管移出石灰水，再熄灭酒精灯，防止石灰水倒吸入热的试管使试管炸裂。
结论：碳具有还原性，能把氧化铜中的铜还原出来（碳是还原剂）。

3二氧化碳（CO₂）

  • 🎈物理性质：无色无味气体，密度比空气大，能溶于水。固体二氧化碳叫"干冰"，升华时吸热，可作制冷剂、用于人工降雨。
  • 🕯️不燃烧、也不支持燃烧：向放有阶梯蜡烛的烧杯中倾倒 CO₂，下层的蜡烛先熄灭、上层的后熄灭——同时说明 CO₂ 不支持燃烧且密度比空气大。因此 CO₂ 可用来灭火。
  • 💧与水反应：CO₂ + H₂O = H₂CO₃，生成的碳酸能使紫色石蕊试液变红；碳酸不稳定：H₂CO₃ = H₂O + CO₂↑。
  • 🥛与石灰水反应（检验 CO₂）：CO₂ + Ca(OH)₂ = CaCO₃↓ + H₂O，澄清石灰水变浑浊——这是检验 CO₂ 的专用方法。
  • 🌱用途：灭火、人工降雨（干冰）、光合作用的气体肥料、制汽水等。
CO₂ + H₂O = H₂CO₃ 碳酸使紫色石蕊变红；受热分解 H₂CO₃ = H₂O + CO₂↑
CO₂ + Ca(OH)₂ = CaCO₃↓ + H₂O 检验 CO₂：澄清石灰水变浑浊

🧪 CO₂ 的实验室制法

  • 💊药品：石灰石（或大理石，主要成分 CaCO₃）与稀盐酸。不用稀硫酸（生成微溶的 CaSO₄ 覆盖表面阻止反应），不用浓盐酸（挥发出 HCl 使气体不纯）。
  • ⚗️装置：固液常温型发生装置（与制 H₂ 相同），长颈漏斗下端要伸入液面以下（液封），防止气体从漏斗逸出。
  • 🫙收集：向上排空气法（CO₂ 密度比空气大且能溶于水，不用排水法）。验满：将燃着的木条放在集气瓶口，木条熄灭则已满。
CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑ 实验室制取二氧化碳的反应原理

制交互三：实验室制取并检验 CO₂

按正确顺序完成五个步骤

①检查气密性 → ②装入石灰石 → ③加入稀盐酸 → ④向上排空气法收集 → ⑤通入石灰水检验
第 1 步：先检查装置的气密性
🔍 操作逻辑
任何气体制取实验都要先检查气密性再加药品；加药品时先固后液（先石灰石、后稀盐酸）。
CO₂ 密度比空气大，用向上排空气法收集，导管要伸到集气瓶底部。
把气体通入澄清石灰水，石灰水变浑浊，证明生成的是 CO₂。

4一氧化碳（CO）

  • 🎈物理性质：无色无味气体，密度比空气略小，难溶于水。
  • 🔥可燃性：2CO + O₂ —点燃→ 2CO₂，燃烧时发出蓝色火焰（煤气、水煤气燃烧）。点燃前必须验纯！
  • 🧲还原性：CO + CuO —加热→ Cu + CO₂，工业上用于冶炼金属（如炼铁：3CO + Fe₂O₃ —高温→ 2Fe + 3CO₂）。
  • ☠️剧毒：CO 极易与血液中的血红蛋白结合（结合能力约为 O₂ 的 200~300 倍），使人缺氧中毒——这就是"煤气中毒"。
2CO + O₂ —点燃→ 2CO₂ CO 的可燃性：蓝色火焰，放热，可作气体燃料
CO + CuO —加热→ Cu + CO₂ CO 的还原性：黑色 CuO 变红；尾气 CO 要处理（点燃或收集），防止污染空气
⚠️ 预防煤气中毒：冬天用煤炉取暖时一定要保持室内通风、装好烟囱；燃气热水器不能安装在浴室内。 CO 无色无味，中毒时难以察觉，发现中毒要立即开窗通风、把病人移到空气新鲜处并就医。

5温室效应与低碳生活

  • 🌍温室效应：大气中的 CO₂ 像温室的玻璃一样，让太阳光通过却阻止热量散失。适量的温室效应使地球适合生命生存；但 CO₂ 过多会导致全球变暖。
  • 📈CO₂ 增多原因：化石燃料的大量燃烧 + 森林砍伐（光合作用减少）。
  • 🌊危害：冰川融化、海平面上升、土地沙漠化、极端天气增多。
  • 🌱低碳生活：随手关灯、绿色出行、植树造林、开发新能源——减少 CO₂ 排放，增强 CO₂ 吸收。

结知识小结

📌 必记要点
碳的单质：金刚石（最硬）、石墨（软、导电）、C₆₀；物理性质差异大是因为碳原子排列方式不同。木炭、活性炭有吸附性（物理变化）。
碳的化学性质：常温稳定；可燃性：C+O₂—点燃→CO₂（充分）、2C+O₂—点燃→2CO（不充分）；还原性：C+2CuO—高温→2Cu+CO₂↑。
CO₂：不燃烧不支持燃烧、密度比空气大、能溶于水、与水生成碳酸、使石灰水变浑浊；实验室制法：CaCO₃+2HCl=CaCl₂+H₂O+CO₂↑，向上排空气法收集，燃着的木条放瓶口验满。
CO：可燃（2CO+O₂—点燃→2CO₂，蓝色火焰）、还原（CO+CuO—加热→Cu+CO₂）、剧毒（与血红蛋白结合）；注意通风防煤气中毒。
CO₂ 过多加剧温室效应 → 全球变暖；倡导低碳生活：减排 + 植树造林。
