1 引入：从面积问题说起

在解决实际问题时，我们常会遇到"已知面积求边长"这类问题。

💡 想一想
有一块矩形花圃，长比宽多 3 米，面积是 18 平方米。设宽为 x 米，则长为 (x+3) 米，依题意列方程：
x(x + 3) = 18
展开整理得：x² + 3x − 18 = 0。
这个方程只含一个未知数 x，且 x 的最高次数是 2——这就是我们要学的一元二次方程！

前面学过的一元一次方程（ax + b = 0）只能解决"一次"关系，而现实中的抛物轨迹、面积、利润最大值等问题，都离不开"二次"。学会解一元二次方程，是打开二次世界大门的钥匙。

2 一元二次方程的定义

方程两边都是整式，只含有一个未知数，并且未知数的最高次数是 2，这样的方程叫做一元二次方程。

ax² + bx + c = 0　(a ≠ 0)
这是一元二次方程的一般形式，其中 x 是未知数
二次项系数

b
含 x 的一次项
常数项
c
不含 x 的项
⚠ 关键提醒
a ≠ 0 是一元二次方程的"底线"。只要 a = 0，无论 b、c 是什么，它就不再是二次方程。另外，方程两边必须是整式（多项式），分式方程（如 1/x + x = 0）不属于一元二次方程。
  • 判断步骤：① 先化成一边为 0 的形式；② 看是否整式方程；③ 确认只有一个未知数且最高次为 2；④ 确认二次项系数 a ≠ 0。
  • 例：x² − 5x + 6 = 0 是一元二次方程（a=1, b=−5, c=6）；x² = 9 也是（即 x² − 9 = 0，a=1, b=0, c=−9）。

4 四种解法

解一元二次方程，常用的有四种方法。它们各有"擅长"的场景：

① 直接开平方法
x² = p (p≥0)
(x + m)² = n (n≥0)
缺一次项或已是完全平方
② 配方法
ax²+bx+c=0 ⟶ (x+m)²=n
万能钥匙，也是推导公式的工具
③ 公式法
x = (−b ± √Δ) / (2a)
Δ = b²−4ac，万能方法
④ 因式分解法
(x−p)(x−q)=0 ⟶ x=p 或 x=q
能"拆"成两个一次因式时最省事
🧠 怎么选？
能因式分解就先分解（最快）；缺一次项用直接开平方；题目要求或公式不好记时用配方法；实在没思路，公式法一定算得出。

5 交互·四种解法对比

用四种方法解同一个方程 x² − 5x + 6 = 0，看看它们殊途同归——结果都是 x = 2 或 x = 3。

第 1 步把方程写成一般形式：x² − 5x + 6 = 0
第 2 步把左边的二次三项式分解因式：
找两数 p、q，使 p + q = −5，p × q = 6。易得 p = −2，q = −3。
第 3 步分解为：(x − 2)(x − 3) = 0
第 4 步两个因式至少一个为 0：
x − 2 = 0 ⟹ x = 2；  x − 3 = 0 ⟹ x = 3
答案x₁ = 2，x₂ = 3
第 1 步移常数项：x² − 5x = −6
第 2 步两边同加一次项系数一半的平方：(−5/2)² = 25/4
x² − 5x + 25/4 = −6 + 25/4
第 3 步左边写成完全平方，右边合并：
(x − 5/2)² = 1/4  （因为 −6 + 25/4 = −24/4 + 25/4 = 1/4）
第 4 步直接开平方：x − 5/2 = ±1/2
第 5 步解出 x：
x = 5/2 + 1/2 = 3；  x = 5/2 − 1/2 = 2
答案x₁ = 2，x₂ = 3
第 1 步确定系数：a = 1，b = −5，c = 6
第 2 步计算判别式：
Δ = b² − 4ac = (−5)² − 4×1×6 = 25 − 24 = 1
第 3 步Δ = 1 > 0，方程有两个不相等的实数根，代入求根公式：
x = (−b ± √Δ) / (2a) = (5 ± √1) / 2 = (5 ± 1) / 2
第 4 步拆成两个根：
x₁ = (5 + 1) / 2 = 3；  x₂ = (5 − 1) / 2 = 2
答案x₁ = 2，x₂ = 3
⚠ 不直接适用
原方程 x² − 5x + 6 = 0 含有一次项 −5x，不是 x² = p 或 (x + m)² = n 的"直接可开方"形式，所以不能直接用直接开平方法求解。
适用形式直接开平方法适用于：
① x² = p（p ≥ 0）⟹ x = ±√p；
② (x + m)² = n（n ≥ 0）⟹ x = −m ± √n。
举例解 x² = 9：
直接开平方得 x = ±√9 = ±3，所以 x₁ = 3，x₂ = −3。
衔接本题若先用配方法得到 (x − 5/2)² = 1/4，便可用直接开平方法完成最后一步（见「配方法」标签）。
✅ 殊途同归
四种方法结果一致：x = 2 或 x = 3。不同方法只是"路径"不同，方程的根是客观存在的。中考时根据题目特征选最快的方法即可。

6 判别式 Δ = b² − 4ac

用公式法时，根号里 b² − 4ac 决定了方程有没有根、有几个根，所以它叫判别式，记作 Δ（读作 delta）。

Δ = b² − 4ac
Δ 的正负决定根的三种情况
Δ > 0
两个不相等的实数根
x₁,₂ = (−b ± √Δ)/(2a)
Δ = 0
两个相等的实数根
x₁ = x₂ = −b/(2a)
Δ < 0
无实数根
（在实数范围内无解）
🧠 几何意义
一元二次方程 ax² + bx + c = 0 的根，就是抛物线 y = ax² + bx + c 与 x 轴交点的横坐标。所以：
Δ > 0 ⟺ 抛物线与 x 轴有两个交点；Δ = 0 ⟺ 一个交点（相切）；Δ < 0 ⟺ 没有交点。

9 根与系数的关系·韦达定理

当一元二次方程 ax² + bx + c = 0（a ≠ 0）有实数根 x₁、x₂ 时，两根与系数之间有如下关系，称为韦达定理：

x₁ + x₂ = −ba      x₁ · x₂ = ca
两根之和 = −b/a，两根之积 = c/a（要求 Δ ≥ 0）
⚠ 注意前提
韦达定理要求方程有实数根（即 Δ ≥ 0）。当 Δ < 0 时，方程无实数根，定理在实数范围内不适用。
  • 不求根也能算两根之和与积——这是韦达定理最大的威力。
  • 已知两根反推方程：方程可写为 x² − (x₁+x₂)x + x₁·x₂ = 0（二次项系数归一）。
  • 检验：求出根后，可用 x₁+x₂ 和 x₁·x₂ 是否等于 −b/a、c/a 来验算。

12 学科交叉参考

🔗 一元二次方程的延伸与应用
  • ➗ 数学·八年级 因式分解—— 因式分解法解一元二次方程，本质就是因式分解！把 ax²+bx+c 分解为 (x−p)(x−q)，由"几个因式之积为 0，则至少一个因式为 0"得根。掌握好因式分解（提公因式、平方差、完全平方、十字相乘），解方程就快了一大半。 代数基础
  • 📊 数学·九年级 二次函数—— 一元二次方程 ax²+bx+c=0 的根，就是二次函数 y=ax²+bx+c 的图像（抛物线）与 x 轴交点的横坐标。判别式 Δ 决定交点个数：Δ>0 两个交点，Δ=0 一个（相切），Δ<0 无交点。方程与函数，是一体两面。 方程与函数
  • ⚡ 物理·九年级 电功率—— 在"电源有内阻"的电路中，外阻 R 变化时，功率 P = E²R/(R+r)² 求最大功率常化为关于 R 的二次式，用"二次函数求最值"或配方法求极值；许多极值问题最终都归结为解或分析一元二次方程。 极值应用
