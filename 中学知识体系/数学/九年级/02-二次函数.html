🎯 引入：生活中的抛物线

先别急着看公式——抬头看看生活，抛物线其实到处都是。

篮球出手后在空中画出一道美丽的弧线，球进没进，就看这条"抛物线"准不准！

💡 想一想
投篮时，球的出手高度、速度方向不同，弧线的高低、宽窄、左右位置都会变。 你能想到吗？这些变化，居然可以用一个公式 y = ax² + bx + c 全部描述！
📖 概念定义

把上面那些曲线抽象成数学语言，就得到了二次函数的定义。

形如 y = ax² + bx + c（a、b、c 是常数，且 a ≠ 0）的函数，叫做二次函数。

为什么叫"二次"？因为自变量的最高次数是 2（x² 项）。它是初中数学里"曲线家族"的第一位成员。

标准抛物线 y = x²：开口向上，对称轴是 y 轴，顶点在原点 (0, 0)。
⚠️ 关键点：x² 的系数 a ≠ 0！如果 a = 0，式子变成 y = bx + c，那就是一条直线（一次函数），根本谈不上"抛物线"了。
  • 🔤 a 叫二次项系数，b 叫一次项系数，c 叫常数项。
  • 🔺 二次函数的图像是一条抛物线，它总是关于一条竖直直线（对称轴）左右对称。
  • 📍 抛物线与对称轴的交点就是它的顶点——开口向上时是最低点，开口向下时是最高点。

① 先把 b、c 都设为 0，只拖 a——看开口方向、宽窄怎么变；
② 再固定 a = 1、b = 0，只拖 c——图像是不是在上下平移？

a — 开口

a > 0 开口向上，有最小值；a < 0 开口向下，有最大值。
|a| 越大，开口越窄（"瘦"）；|a| 越小，开口越宽（"胖"）。

b — 对称轴

b 与 a 一起决定对称轴 x = −b/(2a)。
只动 b 时，图像左右移动、顶点沿一条抛物线"滑行"，但形状不变。

c — 平移

抛物线始终经过点 (0, c)——与 y 轴的交点。
c 增大图像上移，c 减小图像下移，形状和开口都不变。

📍 交互探索 2：顶点坐标与配方法

顶点是抛物线的"心脏"——求最值、画草图都靠它。记住下面的公式，再亲手"配方"一次！

顶点坐标公式：顶点为 ( −b/(2a) , (4ac−b²)/(4a) )，即 h = −b/(2a)，k = c − b²/(4a)
🧠 怎么记？
横坐标 h = −b/(2a) 是对称轴；把 h 代回原式算出 y，就是纵坐标 k。 记住 h = −b/(2a)，就抓住了顶点的一半！

🔄 三种形式：一样的内容，不同的"长相"

同一个二次函数可以用三种形式表示，就像同一个人有不同的照片——怎么方便怎么用！

y = ax² + bx + c（a ≠ 0）
  • 最通用的形式，已知任意三点坐标时用（待定系数法）。
  • 一眼能看到与 y 轴交点 (0, c)。
  • c = 0 时过原点；b = 0 时对称轴就是 y 轴。
y = a(x − h)² + k（a ≠ 0）
  • 顶点直接"摆"在式子里：顶点是 (h, k)，对称轴 x = h。
  • 求最值、描述平移变换时最好用。
  • 可由一般式配方得到：h = −b/(2a)，k = c − b²/(4a)。
y = a(x − x₁)(x − x₂)（a ≠ 0）
  • x₁、x₂ 是抛物线与 x 轴交点的横坐标（即 ax²+bx+c = 0 的两个根）。
  • 仅当抛物线与 x 轴有两个交点时可用；一个交点时退化为 y = a(x−x₀)²。
  • 已知与 x 轴的两个交点时，设交点式最省事。

🔄 三种形式互相转换

形式表达式直接读出什么
一般式y = x² − 4x + 3与 y 轴交于 (0, 3)
顶点式y = (x − 2)² − 1顶点 (2, −1)，对称轴 x = 2
交点式y = (x − 1)(x − 3)与 x 轴交于 (1, 0) 和 (3, 0)
① 配方：一般式 → 顶点式
y = x² − 4x + 3 = (x² − 4x) + 3 = (x − 2)² − 4 + 3 = (x − 2)² − 1
② 因式分解：一般式 → 交点式
y = x² − 4x + 3 = (x − 1)(x − 3)
③ 展开：顶点式 / 交点式 → 一般式（把括号乘开就行）
