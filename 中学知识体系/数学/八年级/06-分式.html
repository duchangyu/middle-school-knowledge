1 分式的定义

如果 A、B 表示两个整式，且 B 中含有字母，那么式子 AB 叫做分式（fraction）。其中 A 叫做分式的分子，B 叫做分式的分母。

分式 = AB （A、B 是整式，B 含字母）
分式是两个整式相除的商，分数线起除号和括号的作用
💡 整式与分式的区别
整式：分母中不含字母。如 x2、x+13、2xπ（π 是常数，不是字母）。
分式：分母中含有字母。如 1x、3x−1、1x+y。
⚠ 易错提醒
π 是常数，不是字母！所以 2xπ 的分母 π 是一个具体的数（约 3.14159…），不含字母，是整式而不是分式。
同理 57 是分数（也是整式），不是分式。
  • 是分式：1x、3x−1、1x+y　——分母含字母
  • 是整式：x2、x+12、x²3　——分母是数，不含字母
  • 是整式（易错）：2xπ　——π 是常数，分母不含字母

3 分式有意义的条件 & 值为 0 的条件

① 分式有意义的条件

在分式 AB 中，当分母 B ≠ 0 时，分式才有意义；当分母 B = 0 时，分式无意义（因为除数不能为 0）。

分式 AB 有意义  ⟺  B ≠ 0
只看分母，与分子无关

② 分式的值为 0 的条件

分式 AB 的值为 0，需要同时满足两个条件：

条件一
分子 A = 0
保证分式的值为 0
条件二
分母 B ≠ 0
保证分式有意义
⚠ 两个条件缺一不可
求分式值为 0 时，必须先解 A=0 得到 x 的值，再代回分母检验 B≠0。如果分母也等于 0，这个 x 要舍去（此时分式无意义，谈不上值为 0）。

例：当 x 为何值时，分式 x²−9x−3 的值为 0？
解：由 x²−9 = 0 得 x = ±3；
检验：x=3 时分母 x−3=0，舍去；x=−3 时分母 x−3=−6≠0，符合。
所以 x = −3。

5 分式的基本性质

分式的分子和分母同乘（或除以）同一个不为 0 的整式，分式的值不变。这是分式变形（约分、通分）的理论基础。

AB = A × MB × M = A ÷ MB ÷ M   (M ≠ 0)
M 必须是不等于 0 的整式，且对原分式有意义
⚠ 三个"同一个"
同乘或同除（不能一个乘一个除）、同一个整式（分子分母必须用同一个 M）、不为 0（M ≠ 0，否则分母变 0 无意义）。
这与小学分数的基本性质完全类似：12 = 24 = 36，分子分母同乘同一个非零数，值不变。
💡 符号法则
分式的分子、分母、分式本身，任意改变其中两个的符号，分式的值不变（因为相当于同乘 −1 两次）。例如：
−a−b = ab；   −ab = a−b = −ab。

7 约分与通分

① 约分——化简分式

把一个分式的分子和分母的公因式约去，叫做分式的约分。约分的关键是找分子分母的公因式，这需要用到因式分解。

A·MB·M = AB （约去公因式 M，M≠0）
约分后分子分母不再有公因式的分式，叫做最简分式
💡 找公因式的方法（与因式分解一致）
① 系数：取分子分母系数的最大公约数。
② 字母：取分子分母都含有的字母。
③ 指数：相同字母取最低次幂。

示例：约分 6x²y9xy²。系数 6, 9 最大公约数 = 3；x 最低次幂 x¹；y 最低次幂 y¹。公因式 = 3xy。约分后 = 2x3y。

② 通分——化异分母为同分母

把几个异分母分式分别化为与原来相等的同分母分式，叫做分式的通分。通分的关键是找最简公分母。

最简公分母 = 各分母系数的最小公倍数 × 各字母最高次幂的积
取"最小"避免数字过大，取"最高次幂"保证能被所有分母整除
💡 通分示例
通分 1x 与 1x+1。
两个分母 x 和 x+1 没有公因式，最简公分母 = x(x+1)。
1x = x+1x(x+1)，   1x+1 = xx(x+1)。

9 分式的运算

分式的四则运算与分数的运算法则完全类似，关键是熟练运用约分和通分。

分式乘法
AB · CD = A·CB·D
分子乘分子，分母乘分母
分式除法
AB ÷ CD = A·DB·C
把除式分子分母颠倒后相乘
同分母加减
AC ± BC = A±BC
分母不变，分子相加减
异分母加减
AB ± CD = A·D±C·BB·D
先通分，化为同分母再加减
⚠ 运算注意事项
乘除法：先因式分解，便于约分；除法先变乘法（颠倒除式）。
加减法：异分母必须先通分，结果要化为最简分式。
混合运算：按"括号→乘除→加减"的顺序，结果务必约简。

12 学科交叉参考

🔗 分式的延伸与应用
  • 🔢 数学·因式分解—— 分式的约分与通分离不开因式分解：把分子分母分解因式后，才能约去公因式；找最简公分母也要先把各分母分解因式。因式分解是分式化简与运算的核心工具。 代数基础
  • √ 数学·二次根式—— 二次根式与分式有相似的化简思想：分式约分去公因式，二次根式化简去完全平方因子。分母有理化（如把 1√2 化为 √22）本质上就是"特殊的通分"。 化简思想
  • 🧪 化学·溶液—— 溶质质量分数 = 溶质质量溶液质量，这就是一个分式！当溶液质量（分母）变化时，溶质质量分数（分式的值）随之变化。理解分式有助于理解溶液稀释、浓缩等计算。 化学应用
