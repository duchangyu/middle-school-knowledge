1 因式分解的定义

把一个多项式化成几个整式的积的形式，叫做因式分解（也叫分解因式）。

多项式  ⟶  几个整式的乘积
因式分解是整式乘法的逆过程
💡 核心特征
因式分解的左边是一个多项式（和差形式），右边是几个整式的乘积。判断一个变形是不是因式分解，就看右边是否是"乘积"的形式，且每个因式都是整式。
  • 是因式分解：x² − 4 = (x + 2)(x − 2)　——右边是两个整式相乘
  • 不是因式分解：(x + 2)(x − 2) = x² − 4　——这是整式乘法（右边是多项式）
  • 不是因式分解：x² + 2x − 1 = x(x + 2) − 1　——右边最后是减法，不是纯乘积
⚠ 易错提醒
因式分解必须进行到每一个因式都不能再分解为止。例如 2a³ − 8a = 2a(a² − 4) 还没结束，因为 a² − 4 还能继续分解为 (a + 2)(a − 2)，最终结果应是 2a(a + 2)(a − 2)。

2 交互·因式分解与整式乘法（互逆关系）

因式分解与整式乘法是互逆过程：整式乘法把"积"展开成"和差"，因式分解把"和差"还原成"积"。点击中间的翻转按钮，观察两个方向的变换。

整式乘法 →
(x+2)(x−3) = x²−x−6
积 ⟶ 和差
互逆
← 因式分解
x²−x−6 = (x+2)(x−3)
和差 ⟶ 积
x²（正）
+2x（正）
−3x（负，减去）
−6（负，减去）
📐 面积模型说明
把 (x+2)(x−3) 看作：(x+2) 乘以 x（得到紫色 x² 和蓝色 2x 两块正面积），再减去 (x+2) 乘以 3（得到橙色 −3x 和红色 −6 两块负面积）。四块合起来：x² + 2x − 3x − 6 = x² − x − 6。这正是"分配律"的几何体现，正向是乘法，反向就是因式分解。

3 提公因式法

如果一个多项式的各项都含有公共的因式，就可以把这个公因式提出来，把多项式化成乘积形式，这种方法叫做提公因式法。

pa + pb + pc = p(a + b + c)
p 是各项的公因式

找公因式的方法

  • ① 系数：取各项系数的最大公约数。
  • ② 字母：取各项都含有的字母。
  • ③ 指数：相同字母取最低次幂。
💡 示例
分解 6x²y + 9xy² − 3xy：
系数 6, 9, −3 的最大公约数 = 3；字母 x 各项都有，最低次幂 x¹；字母 y 各项都有，最低次幂 y¹。
所以公因式 = 3xy。
6x²y ÷ 3xy = 2x，9xy² ÷ 3xy = 3y，−3xy ÷ 3xy = −1。
6x²y + 9xy² − 3xy = 3xy(2x + 3y − 1)

5 公式法

如果把乘法公式反过来用，就可以把某些多项式分解因式，这种方法叫做公式法。

平方差公式
a² − b² = (a + b)(a − b)
两个数的平方差 = 这两数和 × 这两数差
完全平方公式（和）
a² + 2ab + b² = (a + b)²
首平方+尾平方+积两倍 = 两数和的平方
完全平方公式（差）
a² − 2ab + b² = (a − b)²
首平方+尾平方−积两倍 = 两数差的平方
💡 如何识别
平方差：二项式，两项都是平方项，且一正一负（差的形）。
完全平方：三项式，首尾两项都是平方项且同号，中间项正好是首尾两个底数乘积的 ±2 倍。口诀："首平方，尾平方，积的两倍在中央"。
⚠ 注意
x² + 4 虽然两项都是平方，但都是正号（是"和"不是"差"），不能用平方差分解（在实数范围内无法分解）。
x² + 4x + 4 = (x+2)² 中间项 4x = 2·x·2，正好是积的两倍，所以是完全平方式。

7 十字相乘法（拓展）

对于二次项系数为 1 的二次三项式 x² + bx + c，如果能找到两个数 p、q，使得 p + q = b 且 pq = c，那么：

x² + (p + q)x + pq = (x + p)(x + q)
关键：凑出两数之和 = 一次项系数，两数之积 = 常数项
  • 步骤①：写出二次项 x² 的两个因式 x、x（列在左边）。
  • 步骤②：把常数项 c 分解为两个因数 p、q（列在右边）。
  • 步骤③：交叉相乘再相加，检验是否等于一次项系数 b（即 p + q = b）。
  • 步骤④：若相等，横向写出结果 (x + p)(x + q)。
💡 符号规律
常数项为正：p、q 同号，且与一次项系数同号。
常数项为负：p、q 异号，且绝对值较大的因数与一次项系数同号。
例如 x² − x − 6：常数 −6（异号），一次项 −1，所以找两数积 −6、和 −1，即 p=−3、q=2，得 (x−3)(x+2)。

💡 理解"凑数"
十字相乘法的本质是凑数：已知一次项系数 b 和常数项 c，反推两个数 p、q，使 p+q=b、pq=c。当 p=q 时（如 p=q=2），结果是完全平方 (x+2)²；当 q=−p 时（如 p=3,q=−3），中间项消失，结果就是平方差 (x+3)(x−3)。所以完全平方和平方差都是十字相乘的特例！

11 学科交叉参考

🔗 因式分解的延伸与应用
  • 🔢 数学·整式的乘除—— 因式分解与整式乘法是互逆运算！整式乘法把积展开成多项式，因式分解把多项式还原成积。乘法公式 (a+b)(a−b)=a²−b² 反过来用，就是把 a²−b² 分解为 (a+b)(a−b)；完全平方公式反过来，就能识别 a²±2ab+b² 是完全平方式。 互逆运算
  • ➗ 数学·分式—— 分式的约分与通分离不开因式分解：把分子分母分解因式后，才能约去公因式。因式分解是分式化简、运算的核心工具。 代数基础
  • 🧪 化学·化学方程式—— 化学方程式的配平与因式分解有相似的思维：都是寻找"凑数"使两边相等。配平找化学计量数使原子守恒，因式分解找 p、q 使 p+q=b、pq=c，本质都是逆向求解的过程。 配平思维
