形状与大小完全相同的两个三角形——探索 SSS、SAS、ASA、AAS、HL 五大判定方法

1 全等形的定义

定义：能够完全重合的两个图形叫做全等形。

📌 怎样理解"完全重合"
"完全重合"意味着两个图形的形状和大小都相同。把其中一个图形剪下来放到另一个图形上，如果每条边、每个角都能一一对应上，没有任何偏差，它们就是全等形。全等形关注的是形状和大小，与位置和方向无关。

2 全等三角形及其性质

定义：能够完全重合的两个三角形，叫做全等三角形。

记作：△ABC ≅ △DEF（"≅"读作"全等于"）。书写时要求对应顶点的字母按相同顺序排列——A 与 D 对应、B 与 E 对应、C 与 F 对应。

△ABC ≅ △DEF
A↔D, B↔E, C↔F（对应顶点字母顺序一致）

对应要素

  • 对应顶点：A↔D，B↔E，C↔F（重合时叠在一起的顶点）
  • 对应边：AB↔DE，AC↔DF，BC↔EF（重合时叠在一起的边）
  • 对应角：∠A↔∠D，∠B↔∠E，∠C↔∠F（重合时叠在一起的角）
📐 全等三角形的性质
对应边相等，对应角相等。若 △ABC ≅ △DEF，则：
AB = DE，AC = DF，BC = EF；∠A = ∠D，∠B = ∠E，∠C = ∠F。
注意：对应边是对应角所对的边，对应角是对应边所夹的角；不是对应位置的边角不能写成相等。
A ↔ D (红)
B ↔ E (蓝)
C ↔ F (绿)

SSA（边边角）不能判定全等！下面是经典反例：给定 ∠A = 30°、邻边 AC = 8、对边 BC = 5（∠A 的对边），可以画出两个不同的三角形，它们满足相同的 SSA 条件，却形状不同。

✗ 同样满足 SSA 条件，却得到两个不同三角形 → SSA 不能判定全等
📐 为什么会有两个解
以 A 为圆心作 ∠A = 30°，沿角的一边截 AC = 8 得 C 点。再以 C 为圆心、半径 5 画弧，与角的另一边的延长线有两个交点 B₁ 和 B₂。两点都满足 BC = 5，但对应不同的边 AB，因此产生两个不同的三角形。
关键：当对边小于邻边且大于邻边×sin(角)时，会出现两解；只有当角是直角时，SSA 才退化为 HL（可判定）。

AAA（角角角）不能判定全等！三个角对应相等只能保证相似（形状相同），不能保证大小相同。下面是反例：两个等边三角形，三个角都是 60°，但边长不同，因此大小不同，不全等。

✗ 三个角都等于 60°，但边长不等 → AAA 只能相似不能全等
📐 放大缩小不改变角度
任何三角形的三个内角和都是 180°，对三角形做放大或缩小（相似变换）时，角度保持不变，但边长按比例改变。因此仅靠角度无法确定大小，也就无法判定全等。所以 AAA 只能用来判定相似，不能判定全等。

7 交互·HL 直角三角形专题

HL 定理是直角三角形专属的全等判定方法：当两个直角三角形的斜边和一条直角边对应相等时，它们全等。调节下方斜边和直角边长度，观察两个直角三角形始终保持全等。

📐 HL 与 SSA 的关系
HL 看起来像是 SSA（两边和一角），但因为那个角是直角（90°），情况变得特殊：直角是最大的角，没有歧义，所以 SSA 的两解问题消失了，可以唯一确定一个直角三角形。这正说明 HL 是直角三角形中"SSA 的特殊可用情形"。

  • 📐 数学·轴对称—— 全等三角形是研究轴对称的得力工具：作一个点关于直线的对称点，本质就是构造一对全等的直角三角形（由垂直平分线产生）。轴对称的性质证明大量依赖全等三角形（如 SAS、HL）。 对称与全等
