⚗️ 化学方程式

用等式描述化学反应——守恒是核心，配平是关键

一、什么是化学方程式？

化学世界的"等式"——用化学式和数字描述反应前后物质的变化

在数学中我们写过很多等式，比如 2 + 3 = 5。等式两边必须相等——这是等式的本质。

化学方程式就是化学世界的等式。它用化学式表示反应物和生成物，用"+"连接不同物质，用"→"表示反应方向。最关键的一点和数学等式一样：两边必须"相等"——不过这里相等的不是数字，而是原子的种类和数目。

📐 数学等式
2 + 3 = 5
两边的数值相等
遵循：等式的基本性质
🧪 化学方程式
2H₂ + O₂ → 2H₂O
两边原子种类和数目相等
遵循：质量守恒定律
💡 核心思想
化学反应中原子不会凭空产生，也不会凭空消失，只是重新组合。所以反应前后：
① 原子种类不变   ② 原子数目不变   ③ 物质总质量不变

二、书写原则：质量守恒定律

参加化学反应的各物质质量总和，等于反应后生成的各物质质量总和

书写化学方程式必须遵循质量守恒定律，这意味着等号两边各种原子的数目必须相等。我们通过在化学式前加系数来实现——这个过程叫配平。

以氢气在氧气中燃烧为例：

2H₂ + O₂ → 2H₂O
配平后：左边 4 个 H 原子、2 个 O 原子 = 右边 4 个 H 原子、2 个 O 原子

下方可视化展示了反应前后的原子分布。请仔细观察：原子的种类和数量都没有改变，只是组合方式变了——H₂ 和 O₂ 分子拆开后重新组合成了 H₂O 分子。

氢原子 H（白色）
氧原子 O（红色）
⚠️ 注意：如果把方程式写成 H₂ + O₂ → H₂O（没配平），左边有 2 个 H、2 个 O，右边却只有 2 个 H、1 个 O——O 原子数目不等！这违反了质量守恒定律，是错误的化学方程式。

四、交互探索 ②：质量比例计算

根据配平的化学方程式，利用相对分子质量进行质量比例计算

化学方程式不仅告诉我们"什么变成什么"，还告诉我们"按什么质量比反应"。各物质的质量比 = 系数 × 相对分子质量之比。

2H₂ + O₂ → 2H₂O
质量比 = 2×2 : 1×32 : 2×18 = 4 : 32 : 36  （即 1 : 8 : 9）
📐 计算原理
相对原子质量：H=1，O=16，Fe=56，C=12
相对分子质量：H₂=2×1=2，O₂=2×16=32，H₂O=2×1+16=18
所以 4g 氢气完全燃烧需要 32g 氧气，生成 36g 水。

五、常见反应类型

初中化学四大基本反应类型——看清"分合方式"就分得清

① 化合反应
A + B → AB
2H₂ + O₂ → 2H₂O
两种或多种物质结合成一种新物质。特征：多变一。"合"字记心间。
② 分解反应
AB → A + B
2H₂O → 2H₂↑ + O₂↑
一种物质分解成两种或多种物质。特征：一多变。"分"字记心间。
③ 置换反应
A + BC → AC + B
Fe + CuSO₄ → FeSO₄ + Cu
一种单质跟一种化合物反应，生成另一种单质和另一种化合物。"换"位置。
④ 复分解反应
AB + CD → AD + CB
NaOH + HCl → NaCl + H₂O
两种化合物互相交换成分，生成另外两种化合物。条件：生成沉淀、气体或水。
