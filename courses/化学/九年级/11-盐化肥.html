⚗️ 第十一单元：盐 化肥

盐是一大类化合物——由金属离子（或铵根离子 NH₄⁺）和酸根离子构成。 它们既是厨房里的食盐、发酵用的小苏打，也是工业上的纯碱、农田里的化肥。 本单元学习常见盐的性质与用途、复分解反应及其发生条件、 粗盐提纯，以及化学肥料的分类与鉴别。

1生活中常见的盐

🧂 氯化钠 NaCl
食盐的主要成分，白色晶体，易溶于水，水溶液呈中性。
用途：① 调味品、腌制食品；② 配制生理盐水（0.9%）； ③ 农业上选种；④ 工业原料（制取 Cl₂、NaOH 等）；⑤ 公路融雪剂（降低水的凝固点）。
🧪 碳酸钠 Na₂CO₃
俗称纯碱、苏打。白色粉末，易溶于水，水溶液呈碱性。
⚠️ 易错点：纯碱名字带"碱"，但它的水溶液虽呈碱性，分类上属于盐（Na⁺ + CO₃²⁻）！
用途：玻璃、造纸、纺织、洗涤剂的生产。
🍞 碳酸氢钠 NaHCO₃
俗称小苏打。白色细小晶体，能溶于水，受热易分解。
用途：① 发酵粉的主要成分之一（焙制糕点）；② 医疗上治疗胃酸过多。
原理：NaHCO₃ + HCl ═ NaCl + H₂O + CO₂↑
🏛️ 碳酸钙 CaCO₃
大理石、石灰石的主要成分，白色固体，难溶于水。
用途：① 重要的建筑材料；② 实验室制取 CO₂ 的原料；③ 作补钙剂。
与酸反应：CaCO₃ + 2HCl ═ CaCl₂ + H₂O + CO₂↑
💡 "盐"不只是食盐
化学中的"盐"是一大类化合物：由金属离子（或 NH₄⁺）+ 酸根离子构成。 食盐（NaCl）只是其中一种。判断小窍门：看构成粒子，而不是看名字——纯碱（Na₂CO₃）是盐不是碱，水银（Hg）是金属不是银。

2盐的化学性质

  • ① 盐 + 金属 → 新盐 + 新金属（置换反应） 条件：金属要比盐中的金属活泼（K、Ca、Na 除外），盐要可溶。 Fe + CuSO₄ ═ FeSO₄ + Cu　（铁丝表面覆盖红色物质，溶液由蓝色变浅绿色；"曾青得铁则化为铜"——湿法炼铜）
  • ② 盐 + 酸 → 新盐 + 新酸 碳酸盐（或碳酸氢盐）遇酸产生 CO₂ 气体。 CaCO₃ + 2HCl ═ CaCl₂ + H₂O + CO₂↑　／　Na₂CO₃ + 2HCl ═ 2NaCl + H₂O + CO₂↑
  • ③ 盐 + 碱 → 新盐 + 新碱 反应物都要可溶，生成物中要有沉淀（或气体、水）。 Na₂CO₃ + Ca(OH)₂ ═ CaCO₃↓ + 2NaOH　（工业上制取烧碱）
  • ④ 盐 + 盐 → 两种新盐 反应物都要可溶，生成物中至少一种是沉淀。 NaCl + AgNO₃ ═ AgCl↓ + NaNO₃　（白色沉淀，检验 Cl⁻）

3复分解反应及其发生条件

由两种化合物互相交换成分，生成另外两种化合物的反应，叫做复分解反应。 通式：AB + CD → AD + CB（"双交换、价不变"——反应前后各元素化合价不变）。

发生条件：生成物中有 沉淀（↓）、气体（↑） 或 水（H₂O） 生成 三者满足其一即可；都不满足，则反应不能发生。酸碱中和反应（酸+碱→盐+水）也属于复分解反应。

4粗盐提纯

粗盐中含有泥沙等不溶性杂质，通过以下三步可除去： 溶解 → 过滤 → 蒸发。 三步中都要用到玻璃棒，但作用各不相同：溶解时搅拌加速溶解；过滤时引流；蒸发时搅拌防止液滴飞溅。

💡 过滤操作要点——"一贴、二低、三靠"
一贴：滤纸紧贴漏斗内壁（不留气泡）；
二低：① 滤纸边缘低于漏斗边缘；② 漏斗内液面低于滤纸边缘；
三靠：① 倾倒液体的烧杯嘴紧靠玻璃棒；② 玻璃棒下端轻靠三层滤纸一侧；③ 漏斗下端管口紧靠承接滤液的烧杯内壁。
⚠️ 蒸发操作要点
蒸发时要用玻璃棒不断搅拌，防止局部过热造成液滴飞溅； 当蒸发皿中出现较多固体时即停止加热，利用余热将剩余水分蒸干。

5化学肥料

农作物生长需要多种营养元素，其中 N（氮）、P（磷）、K（钾） 需求量最大，需要通过施肥补充。

🌿 氮肥 含 N
作用：促进植物茎、叶生长茂盛，叶色浓绿。缺氮时植株矮小瘦弱、叶片发黄。
常见：尿素 CO(NH₂)₂（含氮量最高的氮肥）、氯化铵 NH₄Cl、硝酸铵 NH₄NO₃、碳酸氢铵 NH₄HCO₃。
🌱 磷肥 含 P
作用：促进作物根系发达，增强抗寒、抗旱能力，使籽粒饱满、提早成熟。
常见：磷矿粉 Ca₃(PO₄)₂（灰白色粉末，难溶于水）、过磷酸钙。
🌾 钾肥 含 K
作用：使茎秆健壮，增强抗病虫害和抗倒伏能力。
常见：氯化钾 KCl、硫酸钾 K₂SO₄、草木灰（主要成分 K₂CO₃，农家钾肥）。
🧬 复合肥料 含 ≥2 种营养元素
同时含有 N、P、K 中两种或两种以上营养元素的化肥。
常见：硝酸钾 KNO₃（含 K 和 N）、磷酸二氢钾 KH₂PO₄、磷酸氢二铵 (NH₄)₂HPO₄。
💡 化肥的简单鉴别
一看外观：氮肥、钾肥多为白色晶体；磷肥多为灰白色粉末——看外观即可先分出磷肥。
二闻气味：碳酸氢铵有强烈的刺激性氨味。
三加熟石灰研磨：铵态氮肥（含 NH₄⁺）会放出有刺激性气味的氨气，钾肥无此现象：
2NH₄Cl + Ca(OH)₂ ═ CaCl₂ + 2NH₃↑ + 2H₂O 据此可检验 NH₄⁺。因此铵态氮肥不能与碱性物质（如草木灰、熟石灰）混合施用，否则会降低肥效！

结知识小结

📌 必记要点
常见盐：NaCl（食盐）、Na₂CO₃（纯碱——是盐不是碱，水溶液呈碱性）、NaHCO₃（小苏打，治胃酸过多）、CaCO₃（大理石/石灰石，建筑材料、补钙剂）。
盐的四条化学性质：盐+金属（置换）、盐+酸、盐+碱、盐+盐（后三种属于复分解反应）。
复分解反应：两种化合物互相交换成分（AB+CD→AD+CB），发生条件：生成沉淀、气体或水。
粗盐提纯：溶解→过滤→蒸发；过滤牢记"一贴二低三靠"；蒸发时不断搅拌、出现较多固体即停热。
化肥：氮肥促叶、磷肥促根和籽粒、钾肥壮茎秆抗倒伏；复合肥含两种以上营养元素（如 KNO₃）。铵态氮肥加熟石灰研磨放出 NH₃（据此检验 NH₄⁺），不能与碱性物质混用。

🚀 中考深度进阶：由浅入深

这一章要真正拿下中考，得把知识从「听懂」练到「用活」。下面分三层进阶：先巩固核心，再提升能力，最后用真实情境检验综合水平。

① 基础巩固

【概念深化】判断物质属于酸、碱、盐、氧化物，要看电离产物：盐由金属离子（或 NH₄⁺）+ 酸根离子构成。纯碱 Na₂CO₃ 水溶液虽呈碱性，但分类是盐不是碱；NH₄⁺ 视作金属离子，所以 NH₄Cl 也是盐。名字带「碱」不一定是碱，名字带「盐」才是盐。

【巩固题】下列物质的名称、化学式与分类对应正确的是？
A. 纯碱 Na₂CO₃ —— 碱
B. 熟石灰 Ca(OH)₂ —— 盐
C. 小苏打 NaHCO₃ —— 盐
D. 水银 Hg —— 盐
② 能力提升

【方法提升】判断复分解反应能否发生，看两种化合物互相交换成分后，生成物是否有沉淀、气体或水。化肥鉴别记三步：一看外观（磷肥多为灰白色粉末）、二闻气味（NH₄HCO₃ 有氨味）、三加熟石灰研磨（铵态氮肥放出 NH₃）；铵态氮肥不能与草木灰等碱性物质混用。

【提升题】下列各组物质在水溶液中混合，能发生复分解反应的是？
A. KNO₃ 与 NaCl
B. Na₂CO₃ 与 Ca(OH)₂
C. CuSO₄ 与 KNO₃
D. NaCl 与 KNO₃
③ 中考综合

【真实情境】中考喜欢把盐的性质、金属活动性、化肥农药结合成综合题：波尔多液用 CuSO₄ 与 Ca(OH)₂ 配制，却不能用铁桶（Fe 比 Cu 活泼，会置换出 Cu）；铵态氮肥遇碱放 NH₃ 降低肥效；化肥真伪鉴别看外观与加碱研磨。要能跨知识点判断「能不能发生反应、产物是什么」。

🌍生态环境波尔多液是常用杀菌农药，由 CuSO₄ 溶液与熟石灰 Ca(OH)₂ 混合配制，存放时不能用铁制容器。原因是？
A. 铁会与 CuSO₄ 发生置换反应：Fe + CuSO₄ → FeSO₄ + Cu，腐蚀铁桶并降低药效
B. 铁会与 Ca(OH)₂ 反应生成铁锈
C. 铁不活泼，与两种物质都不反应，只是成本高
D. 铁与 CuSO₄ 发生复分解反应生成沉淀
