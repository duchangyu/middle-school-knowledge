🧲 电与磁

从磁现象到电磁感应：电流产生磁场，磁场也能产生电流——电动机与发电机的奥秘

🧲 1. 磁现象 —— 磁体与磁极

小时候玩过吸铁石吗？它能吸起铁钉、回形针，却吸不动塑料尺和铜钥匙。这种能吸引铁、钴、镍等物质的性质叫做磁性，具有磁性的物体叫做磁体。

磁极：磁性最强的部位

磁体上磁性最强的两个部位叫做磁极。把条形磁体扔进铁屑堆再拿出来，你会发现两端吸的铁屑最多，中间几乎没有——磁极在磁体的两端。

  • 南极（S 极）：能自由转动的磁体（如小磁针、悬吊的条形磁体）静止时，指南的那个磁极
  • 北极（N 极）：静止时指北的那个磁极
  • 指南针的原理：指南针就是一个小磁针，它的 N 极指向地理北极附近，所以能指示方向

磁极间的相互作用

同名磁极相互排斥， 异名磁极相互吸引

把两辆小车上各放一块条形磁体，N 极对 N 极，轻轻一推，两车会"隔空弹开"；N 极对 S 极，则会"隔空吸拢"。磁力是一种不接触也能产生的力。

磁化

一些物体在磁体或电流的作用下会获得磁性，这种现象叫做磁化。

  • 能被磁化：铁钉、钢针（铁、钴、镍类材料）。钢针磁化后能长期保持磁性，可做指南针
  • 不能被磁化：铜、铝、塑料、木头——所以磁铁吸不住它们
  • 生活应用：磁卡、冰箱贴、螺丝刀磁化后吸小螺丝；危害：机械手表受磁走时不准、磁卡靠近磁铁会消磁
💡 易错辨析
• 每个磁体都有两个磁极，把磁体掰成两段，每一段仍然是"N+S"完整的磁体，不存在单独的 N 极或 S 极
• "相互吸引"不一定是异名磁极——也可能是磁体吸引铁块（铁块本无磁性）；但相互排斥的一定是同名磁极
🧭 2. 磁场与磁感线

磁体之间没有接触，为什么能相互吸引或排斥？因为磁体周围存在一种看不见、摸不着的物质——磁场。磁体间的相互作用就是通过磁场发生的。

  • 磁场的基本性质：对放入其中的磁体产生磁力的作用
  • 磁场的方向：小磁针静止时N 极所指的方向，就是该点磁场的方向
  • 研究方法：用小磁针"探测"磁场——磁场虽然看不见，但能通过小磁针的偏转显现出来（转换法）

磁感线：描述磁场的假想曲线

为了形象、方便地描述磁场，人们仿照铁屑的排列，在磁场中画一些有方向的曲线，叫做磁感线。

磁体外部：磁感线从 N 极 出发，回到 S 极 （磁体内部则从 S 极回到 N 极，形成闭合曲线）
  • 磁感线上任意一点的切线方向 = 该点的磁场方向 = 小磁针静止时 N 极指向
  • 磁感线分布的疏密表示磁场强弱：磁极附近最密，磁场最强
  • 任意两条磁感线不相交（同一点磁场方向唯一）
  • 注意：磁场真实存在，磁感线是为了描述磁场而引入的假想曲线，并不存在！

🧪 交互1：条形磁体的磁场实验室

观察磁感线的分布与小磁针的指向——每个小磁针的方向都是按真实磁场方向（磁偶极子模型）计算的

磁感线方向（外部）：N 极 → S 极
磁极附近：磁感线最密、磁场最强
🎯 观察要点
磁感线从红色 N 极出发，绕一圈回到蓝色 S 极；任意位置的小磁针 N 极（红色）都沿着磁感线切线方向。两极附近磁感线最密——那里磁场最强，铁屑也吸得最多。

🌏 地磁场

地球本身就是一个巨大的磁体，它周围存在的磁场叫做地磁场。指南针能指南北，就是因为受到地磁场的作用。

  • 地磁的两极与地理两极不重合：地磁北极在地理南极附近，地磁南极在地理北极附近
  • 所以指南针的 N 极指向地理北方——因为那里是地磁的 S 极（异名相吸）
  • 地理两极与地磁两极之间的夹角叫做磁偏角。我国宋代的沈括在《梦溪笔谈》中最早记述了磁偏角，比西方早四百多年
💡 记忆窍门
"指北的是 N 极，可北方吸引它的恰恰是地磁 S 极"——地理北极附近 = 地磁南极，千万别记反！
⚡ 3. 电生磁 —— 奥斯特实验与通电螺线管

1820 年，丹麦物理学家奥斯特在课堂上偶然发现：给导线通电的瞬间，旁边的小磁针竟然偏转了！这是人类第一次发现电与磁之间的联系。

奥斯特实验结论：通电导线周围存在磁场（电流的磁效应）， 磁场方向与电流方向有关

🔬 动手做：重现奥斯特实验

点击开关给导线通电/断电，观察小磁针的变化

🎯 现象与结论
断电时，小磁针指向南北方向（受地磁场作用）。闭合开关试试！

通电螺线管：加强版的"电生磁"

把导线绕在圆筒上做成螺线管（线圈），通电后各圈导线产生的磁场叠加在一起，磁场就强多了。实验发现：

通电螺线管外部的磁场和条形磁体的磁场一样——一端相当于 N 极，另一端相当于 S 极
  • 通电螺线管的极性与电流方向有关：电流方向改变，两端的 N、S 极对调
  • 两端极性可用安培定则判断（下一节专门学习）
✋ 4. 安培定则（右手螺旋定则）

通电螺线管的极性与电流方向之间的关系，可以用安培定则来判定：

用右手握住螺线管，让四指指向螺线管中电流的方向，
则拇指所指的那端就是螺线管的 N 极
💡 使用三步曲
① 伸出右手（千万别用左手！）
② 四指弯曲，顺着线圈中电流的方向握住螺线管
③ 竖起拇指——拇指指向的那端就是 N 极

🔩 5. 电磁铁 —— 可控的磁体

在通电螺线管中插入一根铁芯，铁芯被磁化后，磁场会大大增强——这就做成了电磁铁。

影响电磁铁磁性强弱的因素

  • 电流大小：匝数一定时，电流越大，磁性越强
  • 线圈匝数：电流一定时，匝数越多，磁性越强
  • 有无铁芯：插入铁芯后磁性显著增强（铁芯被磁化，磁场叠加）

电磁铁的优点与应用

  • 磁性有无可控：通电有磁性，断电无磁性 → 电磁继电器、电磁起重机
  • 磁性强弱可控：调节电流大小即可 → 电铃、扬声器（喇叭）
  • 极性可控：改变电流方向，N、S 极对调

电磁继电器的本质：用低电压、弱电流的电路去控制高电压、强电流电路的"自动开关"，可实现远距离操纵和自动控制（如温度自动报警器、水位自动报警器）。

🔁 6. 磁场对电流的作用 · 电磁感应

⚙ 磁场对电流的作用 → 电动机

通电导体在磁场中会受到力的作用，力的方向与电流方向和磁感线方向都有关。把通电线圈放入磁场，线圈两边受力方向相反，形成转动力偶，线圈就转起来了。

  • 电动机：利用通电线圈在磁场中受力转动制成，电能 → 机械能
  • 换向器的作用：当线圈由于惯性转过平衡位置（线圈平面与磁感线垂直）时，自动改变线圈中的电流方向，使线圈受力方向不变，从而持续转动下去
  • 生活应用：电风扇、洗衣机、电动车、电吹风……凡是"通电就转"的电器里都有电动机

🔦 磁生电 → 发电机

1831 年，英国物理学家法拉第发现了电磁感应现象：

闭合电路的一部分导体在磁场中做切割磁感线运动时，
导体中就会产生电流——叫感应电流
  • 产生条件（缺一不可）：电路闭合；只有一部分导体；导体做切割磁感线运动
  • 感应电流的方向与导体运动方向和磁场方向有关
  • 发电机：利用电磁感应制成，机械能 → 电能。线圈转一圈，感应电流方向改变两次——发出的是交流电
  • 生活应用：水电站、火电厂、风力发电，手摇手电筒、动圈式话筒

🎛 交互4：电动机 vs 发电机 对比实验

同一台"线圈+磁体"装置：接上电源它是电动机，接上灯泡它就是发电机——注意换向器与滑环的区别！

电动机：有电源，通电线圈受力转动；换向器（两个半环）在转过平衡位置时自动改变电流方向，让线圈持续同向转动。发电机：没有电源，靠外力转动线圈切割磁感线产生感应电流；用滑环（两个整环）引出电流，发出方向周期性变化的交流电——所以灯泡亮度会随转动一闪一闪地脉动！

① 基础巩固

【概念深化】奥斯特实验首次揭示"电生磁"：通电导线周围存在磁场，磁场方向与电流方向有关。通电螺线管外部磁场与条形磁体相似，其极性用安培定则（右手螺旋定则）判断——务必用右手，四指指电流方向，拇指指 N 极。磁感线是描述磁场的假想曲线，并非真实存在。

【巩固题】关于电与磁的基本概念，下列说法正确的是：
A. 用左手握住螺线管，可判断其两端的磁极
B. 用右手握住螺线管，四指指向电流方向，拇指所指的那端是 N 极
C. 通电螺线管的极性与电流方向无关，只与匝数有关
D. 奥斯特实验说明磁能生电
② 能力提升

【方法提升】用安培定则判断极性时，关键是看清"线圈正面（朝向你一侧）导线中的电流方向"。伸出右手，让四指顺着正面电流方向弯曲握住螺线管，拇指指向的那端就是 N 极。可记口诀：正面电流向上→左端 N、右端 S；正面电流向下→右端 N、左端 S。

【提升题】校园科技节上，小明把通电螺线管水平放置，从正面（朝向自己的一侧）看，导线中的电流方向向上。用右手握住螺线管判断，其右端是：
A. S 极（左端为 N 极）
B. N 极（左端为 S 极）
C. 两端都是 N 极
D. 两端都是 S 极
③ 中考综合

【真实情境】电动机与发电机是中考必考的综合点，常以新能源汽车、高铁、风力发电等科技前沿为背景。解题要分清"谁有电源、谁靠外力"：有电源、通电受力转动的是电动机（电能→机械能）；无电源、靠外力转动切割磁感线产生电流的是发电机（机械能→电能，利用电磁感应）。

A. 能量回收时，电机利用"通电线圈在磁场中受力"原理工作
B. 能量回收时，车轮带动线圈在磁场中转动切割磁感线产生感应电流，这是电磁感应，将机械能转化为电能
C. 发电机工作时是将电能转化为机械能
D. 电动车加速前进时，发电机对外供电驱动车轮
