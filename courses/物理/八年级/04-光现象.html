🔦 光现象

从光源到色散，探索光的直线传播、反射、折射与成像规律

☀️ 1. 光从哪里来？——光源与光的直线传播

我们能看见五彩缤纷的世界，是因为有光进入眼睛。那么，光是从哪里来的呢？

光源的分类

能够本身发光的物体叫做光源。光源可分为两大类：

🌌

自然光源

太阳、星星、萤火虫、水母、闪电
💡

人造光源

电灯、蜡烛、火把、霓虹灯、LED灯
💡 注意
月亮不是光源！月亮本身不发光，它只是反射太阳的光。同样，宝石、镜子也不是光源。

光的直线传播

光在同种均匀介质中沿直线传播。我们用一根带箭头的直线来表示光的传播路径和方向，称为光线。

光的直线传播可以解释很多现象：影子的形成、日食和月食、小孔成像等。

小孔成像

把一支点燃的蜡烛放在带小孔的挡板前，在挡板后的光屏上会出现蜡烛倒立的像。这就是小孔成像——光沿直线传播的经典证明。

📝 小孔成像的特点
• 成的是倒立的实像（能被光屏承接）
• 像的形状只与物体形状有关，与小孔形状无关
• 物体越近、光屏越远，像越大
🔄 2. 光的反射定律

光遇到物体表面时会被反射回来，这种现象叫做光的反射。反射时遵循以下规律：

反射定律：入射角 = 反射角　（∠i = ∠r）
入射光线、反射光线和法线在同一平面内，反射光线和入射光线分居法线两侧

说明：入射角是入射光线与法线的夹角，反射角是反射光线与法线的夹角。注意：角度是与法线（不是镜面）的夹角！

拖动下方滑块，调节入射角的大小，观察入射光线和反射光线的变化：

35°
入射角 ∠i = 35°
反射角 ∠r = 35°
入射角 + 反射角 = 70°
🔍 关键理解
• 当入射角减小时，反射角也同步减小（始终相等）
• 当入射角为 0° 时，光线沿原路返回（垂直入射）
• 反射光线与入射光线的夹角 = 2 × 入射角
🌟 3. 镜面反射 vs 漫反射

光射到不同表面上，反射情况不同。反射分为两种类型：

  • 镜面反射：光线射到光滑表面上，反射光线向同一方向射出。反射面光滑：镜子、平静水面、抛光金属。
  • 漫反射：光线射到粗糙表面上，反射光线向各个方向散射。反射面粗糙：纸张、墙壁、黑板。
💡 重要结论
• 镜面反射和漫反射都遵循反射定律（每条光线都满足入射角=反射角）
• 我们能从不同方向看到不发光的物体，正是因为发生了漫反射
• 漫反射让光向各方向散射，使物体从任何角度都能被看见
🪞 4. 平面镜成像

平面镜成像是光的反射现象的重要应用。平面镜成像有以下特点：

  • 等大：像和物体大小相等
  • 等距：像到镜面的距离 = 物到镜面的距离（关于镜面对称）
  • 垂直：像和物的连线垂直于镜面
  • 虚像：由反射光线的反向延长线相交而成，不能用光屏承接
  • 左右相反：像与物左右颠倒（横向翻转）

拖动滑块改变蜡烛到镜面的距离，观察虚像位置的变化（像距始终等于物距）：

60px
物距 = 60px
像距 = 60px
像的大小 = 与物体相等
📐 成像原理
虚像是反射光线的反向延长线（虚线）相交形成的。虚像不能用光屏承接，但可以用眼睛看到。 物体远离镜面时，像也同步远离镜面，像距始终等于物距，像的大小始终不变。
🌊 5. 光的折射

光从一种介质斜射入另一种介质时，传播方向会发生偏折，这种现象叫做光的折射。

斯涅尔定律（折射定律）：n₁ sin θ₁ = n₂ sin θ₂
θ₁ = 入射角，θ₂ = 折射角，n₁ = 入射介质折射率，n₂ = 折射介质折射率
n空气 = 1.0，n水 = 1.33，n玻璃 ≈ 1.5

由公式可得折射角：θ₂ = arcsin( sin θ₁ × n₁ / n₂ )

规律总结：

  • 光从空气射入水（光疏→光密）：折射角 < 入射角，光线靠近法线
  • 光从水射入空气（光密→光疏）：折射角 > 入射角，光线远离法线
  • 当光从光密介质射向光疏介质且入射角足够大时，会发生全反射

调节入射角，观察折射现象。可切换光线的传播方向：

30°
光线方向：
入射角 θ₁ = 30°
折射角 θ₂ = 22.1°
n₁ sinθ₁ = 0.500
⚠️ 全反射！入射角超过临界角（约 48.8°），光线无法进入空气，全部被反射回水中。
🔬 全反射与临界角
当光从光密介质（如水 n=1.33）射向光疏介质（如空气 n=1.00）时，存在一个临界角 θc：
sin θc = n₂ / n₁ = 1.00 / 1.33 ≈ 0.752 → θc ≈ 48.8°
当入射角 ≥ 临界角时，光线全部被反射回原介质，这就是全反射。光导纤维（光纤）就是利用全反射原理传光的。
🌈 6. 光的色散

让一束白光通过三棱镜，白光会被分解成红、橙、黄、绿、蓝、靛、紫七种颜色，这种现象叫做光的色散。

英国物理学家牛顿首先用三棱镜实验发现了光的色散现象，证明了白光是由各种色光混合而成的。

白光 = 红 橙 黄 绿 蓝 靛 紫

色散的原因：不同颜色的光在棱镜中的折射率不同——红光折射率最小（偏折最少），紫光折射率最大（偏折最多）。

🌈 生活中的色散
• 彩虹：雨后空气中有大量小水珠，阳光经水珠折射和反射形成七色光带
• 色散的本质：白光不是单色光，而是由多种色光组成的复色光
• 三原色：红、绿、蓝三种色光按不同比例混合可得到各种色光
