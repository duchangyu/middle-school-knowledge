1 引入：为什么要学三角函数

上一章我们用"相似 + 影子"测旗杆高度，但阴天没有影子怎么办？

其实只要站在离旗杆一段距离处，测出看旗杆顶端的仰角，就能算出旗杆高度。这背后需要一个新工具：锐角三角函数——它建立了直角三角形中锐角的大小与边的比值之间的对应关系。

💡 核心思想

由相似的知识可知：直角三角形中，当锐角 A 的大小确定时，无论三角形放大或缩小，它的对边与斜边之比、邻边与斜边之比、对边与邻边之比都是固定不变的。这些比值只由角度决定，因此可以定义成"角的函数"。

2 正弦、余弦、正切的定义

在 Rt△ABC 中，∠C = 90°。把 ∠A 的对边记作 a（即 BC），∠A 的邻边记作 b（即 AC），斜边记作 c（即 AB）。

sin A = 对边 / 斜边 = a / c
∠A 的正弦（sine）
cos A = 邻边 / 斜边 = b / c
∠A 的余弦（cosine）
tan A = 对边 / 邻边 = a / b
∠A 的正切（tangent）
📌 记忆口诀与注意事项
  • 正弦 = 对/斜，余弦 = 邻/斜，正切 = 对/邻
  • sin A、cos A、tan A 都是比值，没有单位；它们的大小只与 ∠A 有关
  • 由三角形三边关系可知：0 < sin A < 1，0 < cos A < 1，tan A > 0
  • tan A = sin A / cos A（由定义直接推出）
  • ⚠️ 一定要看清是"哪个锐角"的对边和邻边：同一个三角形中，∠A 的对边恰是 ∠B 的邻边

📊 观察要点
  • ∠A 越大（越陡），sin A 越大，cos A 越小，tan A 越大
  • ∠A 接近 90° 时，邻边几乎缩为 0，tan A 会急剧变大（趋向无穷大）
  • 验证一下：任意角度都有 sin²A + cos²A = 1，tan A = sin A / cos A
  • 角度确定 ⇒ 比值确定。这正是"三角函数"名称的由来：比值是角度的函数

🧠 记忆技巧
  • sin 30°、45°、60° = √1/2、√2/2、√3/2（分子根号里依次 1、2、3）
  • cos 正好倒过来：√3/2、√2/2、√1/2（sin 与 cos 互余互换：sin A = cos(90°−A)）
  • tan = sin ÷ cos，所以 tan 30° = √3/3，tan 45° = 1，tan 60° = √3
  • 图形来源：30°-60°-90° 三角形三边为 1 : √3 : 2；45°-45°-90° 三角形三边为 1 : 1 : √2

5 解直角三角形

直角三角形中，除直角外共有 5 个元素（3 条边 + 2 个锐角）。已知其中 2 个元素（至少有一条边），就能求出其余所有元素——这叫做解直角三角形。

  • 三边关系：勾股定理 a² + b² = c²
  • 两锐角关系：∠A + ∠B = 90°
  • 边角关系：sin A = a/c，cos A = b/c，tan A = a/b

6 应用：仰角测高与坡度

  • 仰角与俯角：视线与水平线的夹角。视线在水平线上方叫仰角，在下方叫俯角。
  • 坡度（坡比）i：坡面的铅直高度 h 与水平距离 l 的比，i = h / l = tan α（α 为坡角）。常写成 1 : m 的形式。
  • 方位角：以正北或正南方向为基准，如"北偏东 30°"表示从正北向东转 30°。
旗杆高 = 距离 × tan 仰角 + 眼高
H = d · tan α + h₀ ——仰角测高的核心公式（视线、水平线、旗杆构成直角三角形）

🏔️ 坡度小练习

一段斜坡的坡度 i = 1 : √3，即 tan α = 1/√3 = √3/3，查特殊值表可知坡角 α = 30°。若沿水平方向前进 100 m，则上升高度 h = 100 × tan 30° = 100√3/3 ≈ 57.7 m。

8 学科交叉参考

🔗 锐角三角函数在其他学科中的应用
  • ⚡ 物理·力（力的分解）—— 把一个力沿两个互相垂直的方向分解，本质上就是三角函数：若力 F 与水平方向夹角为 θ，则水平分力 F·cos θ，竖直分力 F·sin θ。斜面上物体的重力分解为沿斜面的 G·sin θ 和垂直斜面的 G·cos θ。 力的分解
  • ⚡ 物理·简单机械（斜面）—— 斜面省力与坡角有关：沿斜面匀速推物体所需拉力约等于 G·sin θ，坡角越小（斜面越平缓）越省力——盘山公路就是利用这个原理。 斜面
  • 📐 数学·相似—— 三角函数值"只由角度决定"的根本原因就是相似：锐角相同的直角三角形彼此相似，对应边的比值相等。 相似
