1 幂的运算性质

幂的运算是整式乘除的基础。aⁿ 表示 n 个 a 相乘（n 为正整数），即 aⁿ = a · a · … · a。下面是五条基本运算性质：

① 同底数幂相乘
aᵐ · aⁿ = aᵐ⁺ⁿ
底数不变，指数相加
② 幂的乘方
(aᵐ)ⁿ = aᵐⁿ
底数不变，指数相乘
③ 积的乘方
(ab)ⁿ = aⁿbⁿ
每个因式分别乘方
④ 同底数幂相除
aᵐ ÷ aⁿ = aᵐ⁻ⁿ
a≠0，底数不变指数相减
⑤ 零指数幂
a⁰ = 1
a≠0，任何非零数的 0 次幂等于 1
💡 记忆口诀
乘法加、乘方乘、除法减 —— 同底数幂相乘指数相加；幂的乘方指数相乘；同底数幂相除指数相减。注意区分 aᵐ · aⁿ（指数加）与 (aᵐ)ⁿ（指数乘）。

3 整式的乘法

整式的乘法分三种情况，核心都是分配律的运用。

  • ① 单项式 × 单项式：系数相乘、同底数幂相乘、单独字母连同指数照抄。
    例：2x²y · 3xy² = (2×3) · x²⁺¹ · y¹⁺² = 6x³y³
  • ② 单项式 × 多项式：用单项式去乘多项式的每一项，再把积相加。
    公式：m(a + b + c) = ma + mb + mc
  • ③ 多项式 × 多项式：用一个多项式的每一项乘另一个多项式的每一项，再把积相加。
    公式：(a + b)(m + n) = am + an + bm + bn
(a + b)(m + n) = am + an + bm + bn
多项式乘多项式：先展开再合并同类项

5 乘法公式

乘法公式是特殊形式的多项式乘法，熟记后可直接写出结果，不必再慢慢展开。本章学习两个最重要的公式：

平方差公式
(a + b)(a − b) = a² − b²
两数和 × 两数差 = 两数平方差
完全平方公式（和）
(a + b)² = a² + 2ab + b²
两数和的平方 = 平方和 + 两倍乘积
完全平方公式（差）
(a − b)² = a² − 2ab + b²
两数差的平方 = 平方和 − 两倍乘积
⚠ 易错提醒
(a ± b)² ≠ a² ± b²！完全平方公式中间一定有 ±2ab 这一项，是最容易遗漏的。口诀："首平方，尾平方，积的两倍在中央"。

7 整式的除法

整式的除法同样分两种情况，是乘法的逆运算。

  • ① 单项式 ÷ 单项式：系数相除、同底数幂相除（指数相减）、单独字母连同指数照抄。
    例：6x³y³ ÷ 2xy² = (6÷2) · x³⁻¹ · y³⁻² = 3x²y
  • ② 多项式 ÷ 单项式：把多项式的每一项分别除以单项式，再把商相加。
    公式：(am + bm + cm) ÷ m = a + b + c
(ambmcm) ÷ m = ambmcm ÷ m = a + b + c
多项式除以单项式：先分配再分别相除
⚠ 注意
多项式 ÷ 多项式 不在本章要求内（那是高中"长除法"的内容）。本章只学多项式 ÷ 单项式。
