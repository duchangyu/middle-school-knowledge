📐 三角形

几何世界的基石——三条线段首尾相接，撑起稳固的形状与 180° 的内角和

首页 / 数学 / 八年级 / 三角形

1 三角形的定义与要素

定义：由不在同一条直线上的三条线段首尾顺次相接组成的平面图形，叫做三角形。

三角形包含三个要素：

  • 三条边：组成三角形的三条线段，记作 a、b、c
  • 三个顶点：两条线段的公共端点，记作 A、B、C
  • 三个内角：相邻两边组成的角，记作 ∠A、∠B、∠C
📌 记法与约定
三角形记作 △ABC。其中：边 a = BC（∠A 的对边），边 b = AC（∠B 的对边），边 c = AB（∠C 的对边）。"对边"指角正对面的那条边。

4 三角形的三边关系

定理：三角形任意两边之和大于第三边，任意两边之差小于第三边。

|a − b| < c < a + b
（对任意一条边 c 都成立，可等价写作 a+b>c、a+c>b、b+c>a）
📐 为什么成立？
两点之间线段最短：从 A 到 C，直走（边 b）一定比绕道经过 B（边 a+c）更短，所以 b < a + c。同理可证其余两个不等式。两边之差小于第三边可由移项得到。

6 三角形内角和定理

定理：三角形三个内角的和等于 180°。

∠A + ∠B + ∠C = 180°
这是平面几何的基本定理之一，适用于所有三角形
📐 证明思路（拼角法）
过三角形一个顶点作对边的平行线，利用"两直线平行，内错角相等"把三个内角凑成一个平角（180°）。也可以用"撕角拼合法"——把三个角剪下来拼在一起，正好拼成一条直线。

8 三角形的高、中线、角平分线

高（蓝）

从三角形一个顶点向它所对的边所在直线作垂线，顶点和垂足间的线段。

中线（绿）

连接三角形一个顶点和它所对边的中点的线段。

角平分线（橙）

三角形一个内角的平分线与它对边相交，顶点和交点间的线段。

切换三角形类型与线段类型，观察高在不同三角形中的位置变化——高可能在三角形内部、边上或外部。

🔍 观察
锐角三角形的三条高都在三角形内部，它们交于一点（垂心）。

9 三角形的外角性质

定义：三角形的一边与另一边的延长线组成的角，叫做三角形的外角。

外角 = 不相邻的两个内角之和
三角形的一个外角等于与它不相邻的两个内角的和
📐 推论
由内角和 180° 可知：∠A + ∠B + ∠C = 180°，而 ∠C 的外角 = 180° − ∠C = ∠A + ∠B。
所以三角形的外角大于任何一个和它不相邻的内角。

10 三角形的稳定性

稳定性：当三角形的三条边长确定后，三角形的形状和大小就完全确定，不会改变。这个性质叫做三角形的稳定性。

💡 生活中的稳定性
桥梁桁架、起重机吊臂、自行车车架、屋顶钢架……都使用了三角形结构来保证稳固。而四边形（如推拉门）因为形状可变，常被用在需要灵活变形的地方。

11 交互·稳定性实验

用鼠标拖动顶点：左侧三角形顶点拖动时整个三角形平移、形状不变（三边长度固定，刚体）；右侧四边形顶点拖动时形状改变（不稳定）。点击"还原"恢复初始位置。

🔺 三角形（稳定）

三条边长度固定 → 形状不变

⬜ 四边形（不稳定）

四条边可绕顶点转动 → 形状可变
